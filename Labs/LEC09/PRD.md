# Sonic 애니메이션 뷰어 PRD

- 문서 상태: 개발 기준안
- 기준 입력: `PRE_PRD.md`
- 대상 폴더: `Labs/LEC09`
- 기준일: 2026-10-06

## 1. 제품 개요

`sonic-sprite.png`에 들어 있는 Sonic 스프라이트를 키보드로 조작해 애니메이션과 화면 이동을 확인하는 간단한 데스크톱 뷰어를 만든다. 서 있기, 걷기, 달리기, 구르기, 급제동·방향 전환, 점프 동작을 보여주며, 걷기·달리기·구르기는 화면 안에서 실제 위치가 변한다.

## 2. 목표와 결과물

### 목표

- 키보드 조작에 따라 지정한 이미지 프레임을 순서대로 재생한다.
- 동작별 속도에 맞게 캐릭터를 움직인다.
- 캐릭터가 창 경계에 닿으면 경계를 넘어가지 않도록 멈추되, 입력된 동작 애니메이션은 계속 재생한다.
- 넓은 화면에서 스프라이트를 충분히 크게 표시하고 프레임을 잘리지 않게 한다.

### 결과물 및 기술 제약

- Python 파일: `sonic_animation_viewer.py`
- 그래픽 라이브러리: `pico2d`
- 스프라이트 이미지: 프로젝트 폴더의 `sonic-sprite.png`
- 창 크기: **1200×600 픽셀**
- Python 구현은 단일 파일로 유지한다. 이미지 경로는 현재 작업 디렉터리가 아닌 스크립트 파일 위치를 기준으로 찾는다.
- 실행에 필요한 외부 애니메이션 데이터 파일이나 추가 Python 모듈을 만들지 않는다.

## 3. 사용자 입력, 애니메이션 및 이동

| 입력 상태 | 애니메이션 및 이동 |
| --- | --- |
| 좌우 방향키 입력 없음 | 바라보는 방향의 서 있기 애니메이션을 반복하고 현재 위치에 머문다. 시작 방향은 오른쪽이다. |
| 왼쪽 또는 오른쪽 방향키 | 해당 방향의 걷기 애니메이션을 재생하고 초당 180픽셀로 수평 이동한다. |
| 방향키와 Shift | 해당 방향의 달리기 애니메이션을 재생하고 초당 360픽셀로 수평 이동한다. |
| 방향키와 Shift를 1.0초 이상 계속 누름 | 1.0초가 되면 구르기 시작 애니메이션을 재생한 뒤 구르기 반복 애니메이션으로 전환한다. 구르는 동안 초당 420픽셀로 수평 이동한다. |
| 구르기 중 Shift 또는 방향키 해제 | 남은 입력에 따라 달리기, 걷기 또는 서 있기 상태로 전환한다. |
| 달리는 중 반대 방향키 입력 (Shift 유지) | 급제동·방향 전환 애니메이션이 재생되는 동안 이동을 멈춘다. 전환이 끝난 뒤 새 방향 입력이 유지되면 새 방향으로 달리기 시작한다. 방향키 입력이 없으면 현재 입력 상태에 맞는 걷기 또는 서 있기 상태로 돌아간다. |
| Space | 0.72초 동안 점프 애니메이션과 수직 점프 궤적을 재생한다. 점프 중 방향키를 누르면 해당 방향으로도 움직인다. Shift와 방향키를 함께 누르면 수평 속도는 달리기 속도, 방향키만 누르면 걷기 속도를 사용한다. 수평 방향 입력이 없으면 제자리에서 뛴다. |
| Esc | 뷰어를 종료한다. |

이동 속도와 점프 시간·높이는 조정 가능한 상수로 둔다. 위 값은 초기 기준값이다. 점프 높이는 기본 150픽셀로 하고, 시간에 따른 포물선 형태로 상승 후 착지시킨다. 이동 위치는 프레임마다 경과 시간(`delta time`)을 반영해 계산한다.

좌우 키를 동시에 누르면 마지막으로 눌린 방향키를 이동 의도로 사용한다. 키 반복 이벤트에 의존하지 않고 눌림·해제 상태를 추적한다. 점프는 일반 이동 애니메이션보다 우선한다. 점프 중 방향 입력은 바라보는 방향과 수평 이동에 반영한다. 구르기 지속 시간은 방향키와 Shift가 함께 눌린 연속 시간으로 계산한다.

## 4. 화면, 경계 및 애니메이션 프레임

### 화면과 이동 경계

- 창은 1200×600 픽셀로 연다. 캐릭터 스프라이트의 투명 여백을 제외한 실제 크기에 맞춰 표시 배율을 정하고, 모든 동작에서 잘리지 않게 한다.
- 캐릭터는 처음에 창 가로 중앙 부근, 바닥 기준선 위에 둔다. 바닥 기준선은 창 아래에서 80픽셀 위를 초기값으로 한다.
- 좌우 경계 판정은 사용 프레임 중 가장 넓은 37픽셀 프레임을 기준으로 고정해 프레임 너비가 바뀔 때 위치가 흔들리지 않게 한다. 왼쪽·오른쪽 끝에서 바깥쪽으로 이동하려 하면 수평 위치를 경계에 고정한다. 점프 중 위쪽 경계에 닿으면 수직 위치를 고정한다.
- 경계에서 이동이 멈춰도 입력에 해당하는 걷기·달리기·구르기 애니메이션은 그대로 재생한다. 반대 방향 입력을 받으면 그 방향으로 다시 이동할 수 있다. 화면 반대편으로 순간 이동하거나 캐릭터를 다시 중앙으로 보내지 않는다.
- 배경은 스프라이트와 대비되는 단색으로 둔다. 바닥 기준선을 표시할 경우 캐릭터 확인을 방해하지 않도록 얇게 그린다.

### 스프라이트 시트 이미지와 프레임 간격

`sonic-sprite.png` 한 장을 사용한다. 원본에는 고정 셀 격자가 없으므로 제목·크레딧을 제외하고 위에서부터 캐릭터가 배열된 행을 `R1`, `R2` …로, 각 행 안의 그림을 왼쪽부터 `F1`, `F2` …로 부른다. 아래 프레임 번호는 1부터 센다. 구현 단계에서 각 프레임의 실제 픽셀 사각형을 확인해 코드에 기록한다. 좌우 원본 프레임이 하나뿐인 동작은 가로 반전해서 반대 방향으로 표시한다.

| 동작 | 사용할 이미지 프레임 (원본 `sonic-sprite.png`) | 프레임당 표시 시간 | 재생 방식 |
| --- | --- | --- | --- |
| 서 있기 | `R1-F1`부터 `R1-F7`까지 | 0.16초 | 순환 |
| 걷기 | `R2-F1`부터 `R2-F12`까지 | 0.08초 | 순환 |
| 달리기 | `R3-F1`부터 `R3-F6`까지 | 0.06초 | 순환 |
| 구르기 시작 | `R4-F1`부터 `R4-F9`까지 | 0.07초 | 한 번 재생한 뒤 구르기 반복으로 전환 |
| 구르기 반복 | `R5-F1`부터 `R5-F6`까지 | 0.07초 | 순환 |
| 급제동·방향 전환 | 현재 방향의 달리기 프레임 `R3-F6`→`R3-F1`, 이어 새 방향의 `R3-F1`→`R3-F3` | 0.05초 | 한 번 재생. 전환 중 위치 이동은 정지 |
| 점프 | `R5-F1`부터 `R5-F6`까지 | 0.08초 | 점프가 끝날 때까지 순환. 전체 점프 시간은 0.72초 |

`R1`부터 `R5`는 제목 아래 첫 번째부터 다섯 번째 캐릭터 행을 뜻한다. 이 기준 프레임이 실제 이미지에서 의도한 포즈와 맞는지 첫 구현 단계에서 확인하고, 코드에 기록한 프레임 사각형과도 대조한다. 급제동·방향 전환용 별도 그림은 시트에서 명확히 구분되지 않으므로 달리기 그림을 역순 재생한 뒤 새 방향으로 전환하는 방식으로 표현한다. 프레임당 표시 시간은 표의 값을 기준으로 시작하며, 자연스러운 재생을 위해 조정할 경우 PRD와 코드 상수를 함께 갱신한다.

## 5. 기능 요구사항

- **FR-1 입력 추적:** 좌우 방향키, Shift, Space의 눌림·해제 상태를 추적한다.
- **FR-2 기본 상태:** 입력이 없을 때 서 있기 프레임 7개를 각 0.16초씩 표시하며 반복하고 위치를 유지한다.
- **FR-3 걷기 및 이동:** 좌우 입력에 따라 걷기 프레임 12개를 각 0.08초씩 반복하고 초당 180픽셀로 이동한다.
- **FR-4 달리기 및 이동:** 방향키와 Shift가 함께 눌리면 달리기 프레임 6개를 각 0.06초씩 반복하고 초당 360픽셀로 이동한다.
- **FR-5 구르기 및 이동:** 조합 입력이 1.0초 유지되면 구르기 시작 프레임 9개를 각 0.07초씩 재생한 뒤, 구르기 프레임 6개를 각 0.07초씩 반복하고 초당 420픽셀로 이동한다. 조합이 해제되면 이동 입력에 맞는 상태로 복귀한다.
- **FR-6 급제동·방향 전환:** 달리는 중 반대 입력이 들어오면 지정된 달리기 프레임 시퀀스를 각 0.05초씩 재생하고, 전환 중 수평 이동을 멈춘다. 이후 새 방향의 입력에 맞게 이동을 재개한다.
- **FR-7 점프 및 이동:** Space 입력으로 0.72초 점프를 실행한다. 구르기 프레임 6개를 각 0.08초씩 순환하고, 기본 최대 높이 150픽셀의 수직 궤적을 적용한다. 방향키가 눌린 경우 해당 방향의 수평 이동도 적용한다.
- **FR-8 화면 표시 및 경계:** 1200×600 창에서 캐릭터를 확대해 표시한다. 캐릭터의 실제 스프라이트 경계가 창 경계를 넘지 않도록 위치를 제한하며, 경계에 닿아도 현재 이동 애니메이션을 지속한다.
- **FR-9 종료 및 오류 안내:** Esc 또는 창 닫기로 정상 종료한다. Pico2D 초기화 또는 이미지 로드가 실패하면 원인을 알 수 있는 오류를 출력한다.

## 6. 품질 및 수용 기준

다음 항목을 직접 실행해 확인하면 1차 완료로 본다.

1. 프로젝트 폴더에서 `python sonic_animation_viewer.py`로 실행할 수 있다.
2. 창 크기가 1200×600이며, `sonic-sprite.png` 캐릭터가 잘리지 않고 충분히 크게 표시된다.
3. 입력이 없으면 지정된 서 있기 프레임과 0.16초 간격이 반복되고 캐릭터가 제자리에 머문다.
4. 좌우 방향키 각각에서 걷기 프레임이 0.08초 간격으로 재생되고 캐릭터가 해당 방향으로 초당 180픽셀 이동한다.
5. 좌우 방향키와 Shift 조합에서 달리기 프레임이 0.06초 간격으로 재생되고 초당 360픽셀 이동한다.
6. 조합 입력 1.0초 후 구르기 시작 이미지가 재생되고, 이어 구르기 이미지가 0.07초 간격으로 반복되며 초당 420픽셀 이동한다.
7. 달리는 중 반대 방향을 입력하면 지정된 이미지로 급제동·방향 전환이 재생되고, 전환 중 이동이 멈춘 뒤 새 방향으로 이동한다.
8. Space를 누르면 지정된 점프 이미지와 0.72초 수직 궤적이 재생된다. 방향키를 함께 누르면 해당 방향으로도 이동하고, 종료 후 입력에 맞는 상태로 돌아온다.
9. 걷기·달리기·구르기로 좌우 경계에 도달하면 위치는 더 변하지 않지만 해당 애니메이션은 계속 재생된다. 반대 방향 입력으로 경계에서 떨어져 나올 수 있다.
10. 점프 중 위쪽 경계에 닿아도 이미지 재생은 지속되고, 화면 밖으로 그려지지 않는다.
11. 반복 애니메이션은 순환하고, 한 번만 재생하는 전환 동작은 마지막 프레임까지 표시한다.
12. Esc와 창 닫기가 모두 정상 동작한다.

## 9. 구현 전 확인 사항

- `sonic-sprite.png`는 399×525 픽셀이다. 제목·크레딧을 제외한 캐릭터 행과 프레임별 픽셀 사각형을 확인해 코드에 기록한다.
- 표에 정의한 R1~R5 이미지가 서 있기·걷기·달리기·구르기 포즈에 맞는지 확대 화면에서 확인한다. 시트에 별도 급제동 그림이 명확하지 않으면 PRD에 정한 달리기 프레임 역순 연출을 사용한다.
- 기본 프레임 간격, 동작별 이동 속도, 점프 시간·높이는 위 표의 초기값으로 시작한다. 조정할 경우 코드와 문서를 함께 갱신한다.
