소닉 애니메이션 뷰어 작성

파일 이름 sonic_animation_viewer.py
개발언어 Python
라이브러리 pico2d
단일 파일로만 작성
sonic-sprite.png 스프라이트 이미지 사용

기능
키보드 입력에 따라 애니메이션이 출력되게 할 것
입력 없을 시 서있는 애니메이션
좌우 화살표 키보드 입력 시 해당 방향으로 걷는 애니메이션
좌우 방향키를 누른 채 시프트 키 입력 시 해당 방향으로 달리는 애니메이션
좌우 방향키를 누른 채 시프트 키 입력 시간이 일정 시간을 지나면 구르는 애니메이션

좌/우 방향키를 누른 채 시프트 키 입력 도중 반대 방향 화살표 키 누르면 급제동 및 방향 전환 애니메이션

스페이스 키를 입력 시 점프하는 애니메이션


화면 대비 이미지가 잘 보이도록 충분히 확대할 것
한번에 전부 개발하지 말고, 단계별로 구현하며 커밋을 단계마다 적절히 커밋 메시지를 작성하며 커밋할 것
최소 개발단계: 20단계
